# 考研错题本 · AI 协作版

一个「**把错题拍照丢给 AI，剩下的它来做**」的考研复习库。基于 Markdown + Obsidian，配合任意能读 `AGENTS.md` 的 AI 工具使用（ZCode / Qoder / WorkBuddy / Cursor / Claude Code 等）。

核心思路：**你不填空，只纠错。** 拍一张错题照片发过去，AI 负责转写题目、判断科目/模块/题型/知识点/错因、查重、按统一格式归档，并给出一行判断依据供你一眼核对。

```
手机拍照 ──同步盘──▶ 收件箱/ ──AI 归档──▶ 错题/ ──FSRS 排期──▶ 到期提醒
                                                                    │
              重做单(无答案) ◀──每周生成── 周末总结 ◀──────────────┘
                    │
                 纸上重算 → 回填结果（拍照/口头/手改）→ 调度更新
```

---

## 它解决什么问题

手动整理错题本的三个痛点，这里都有针对性设计：

| 痛点 | 这里的做法 |
|---|---|
| 抄题、画格子、分类，费时又容易半途而废 | 拍照发图即可，AI 转写并归档；你不用敲命令、不用分类 |
| 整理完就再也没看过 | `next_review` + **FSRS 间隔重复**，AI 每次对话开场主动报告今天的到期题和收件箱积压 |
| 同一道题反复错、同一个知识点反复抄 | 强制查重：同一道题只加一行「重做记录」，错 3 次自动打 `高频错题` 标签 |
| 对着答案"重做"，其实在骗自己 | 每周生成**不含答案**的可打印「重做单」，在纸上真算一遍 |

## 你需要准备什么（三档门槛）

- **第 1 档 · 已经在用任一 AI 编程工具**（ZCode / Qoder / WorkBuddy / Cursor / Claude Code…）：直接跳到「三步上手」。
- **第 2 档 · 只用过 Obsidian**：再装一个能读 `AGENTS.md` 的 AI 工具（有免费额度即可用起来，推荐 ZCode 这类终端型工具），无需编程知识。
- **第 3 档 · 两个都没用过**：先花一个晚上装 Obsidian + 任一第 2 档里的 AI 工具；本框架不需要你写代码，只需要习惯"跟 AI 说话"。若这也不想装，本框架不适合你——它没有 App、没有服务器，这正是隐私可控、规则可审计的代价。

## 三步上手

### 1. 装 Obsidian，把本库作为库打开

到 [obsidian.md](https://obsidian.md) 下载安装（免费）。打开时选择「**以文件夹作为库打开**」，指向本仓库的文件夹。

> 视图用的是 Obsidian **内置的 Bases**（`错题-总览.base` / `错题-按科目.base`），**不需要装任何插件**。**要求 Obsidian ≥ 1.9**，旧版本请先升级。

### 2. 填 `个人配置.md`，告诉 AI 用这个目录

把仓库里 `个人配置.md` 的【待填】逐项换成你自己的信息（考试目标、书单、同步通道）——规则文件都会引用它。然后用你惯用的 AI 工具，**把本库文件夹设为工作目录**，说一句：

```
启动项目
```

AI 会确认目录、读取 `AGENTS.md` 里的完整规则并做首题试跑。之后直接发错题图片就行。

### 3. 开始发图

- 发**错题照片** → 自动归档（手机拍：照片丢进同步盘对应目录即自动进 `收件箱/`，电脑开机后 AI 自动清账）
- 发**生词** → 记进单词本，补齐考研常考义项和搭配
- 说 **"今天该重做什么"** → 出复习清单
- 说 **"出重做单"** → 生成可打印的无答案重做单
- 说 **"处理收件箱"** → 归档 `收件箱/` 里拖进去的图片

## 复习调度：FSRS 间隔重复

不再固定 +3/+7/+30 天：`工具/库维护.py` 内置 **FSRS-4.5 算法**（纯标准库、零第三方依赖），按每道题全部的复习历史计算下次重做间隔——做错很快回来，连对则大幅拉长。每次对话开场，AI 会先跑脚本报告「今日到期 N 道 · 收件箱待处理 M 张」，复习不会静默脱节。

说「刷新工作台」可生成 `工作台.html`——零依赖的单文件本地仪表盘（双击浏览器打开）：今日到期、科目/错因分布、哪本书错得最多、高频错题榜、未来两周复习负载，数据直接来自错题笔记，随归档自动刷新。

├── 归档细则.md            ← 英语错题、生词、收件箱、重做单的细化规则

├── 错题-总览.base         ← Bases 视图（待复习/高频/按材料…）
├── 错题-按科目.base       ← Bases 视图（数学/英语/政治/专业课）
├── 工具/库维护.py         ← lint / 统计 / 到期清单 / FSRS 调度 / 工作台 / pull·push(WebDAV) / 周报（零依赖）
├── 错题/<科目>/           ← 错题笔记（每道题一个 md）
├── 知识点/                ← 公式手册、方法速查、单词本、作文语料…
├── 模板/                  ← 错题笔记模板、个人配置模板
├── 收件箱/                ← 黑洞区：图片拖进来等 AI 归档
│   ├── 已处理/            ← 归档后原图移到这里
│   └── 待确认/            ← AI 看不懂的，不猜，放这里等你说明
├── 重做单/                ← 生成的可打印重做清单
├── 附件/                  ← 错题原图

## 关于 AI 工具

`AGENTS.md` 是一份**工具无关**的规则文件，用相对路径描述一切库内位置，因此可以原样复制到任何机器、任何目录。

| 工具 | 自动读取 `AGENTS.md` |
|---|---|
| ZCode | 是 |
| Qoder | 是 |
| WorkBuddy | 是（引导文件有 8000 字符上限；本文件控制在 5000 内，跑 `python 工具/库维护.py check-agents` 可验证） |
| Cursor / Claude Code 等 | 大多支持 |

`.zcode/commands/` 下的 `/cuoti`、`/fuxi` 只对 **ZCode** 有效，用别的工具可直接忽略——它们只是少打几个字的捷径。

## 可选：让它自动跑

本库支持两条**可选**的定时任务（不配也完全能用，手动说一句即可）：

- **每周日 10:00** —— 生成当周重做单
- **每天 23:00** —— 扫描 `收件箱/` 并归档

完整任务规格见 `启动项目.md`（提示词里的 `【库根目录】` 替换成你的真实路径即可），在你所用 AI 工具的「自动化 / 定时任务」入口里建一遍。没有定时任务也不影响核心体验：每次对话开场的被动检查会主动报积压。

## 隐私说明

本库是**空框架**：所有笔记都是模板、说明文字和空表格，**不含任何已有错题或个人信息**。规则文件通篇用相对路径，不绑定任何本机路径；你的个人事实只存在 `个人配置.md`（模板不含隐私），发布或分享时不要带出它的真实版。坚果云凭据写在 `工具/.nutstore`，已被 gitignore，**永不入库**。你可以安全地复制、修改、再分发。
