# 考研错题本 · AI 协作版

一个「**把错题拍照丢给 AI，剩下的它来做**」的考研复习库。基于 Markdown + Obsidian，配合任意能读 `AGENTS.md` 的 AI 工具使用（ZCode / Qoder / WorkBuddy / Cursor / Claude Code 等）。

核心思路：**你不填空，只纠错。** 拍一张错题照片发过去，AI 负责转写题目、判断科目/模块/题型/知识点/错因、查重、按统一格式归档，并给出一行判断依据供你一眼核对。

---

## 它解决什么问题

手动整理错题本的三个痛点，这里都有针对性设计：

| 痛点 | 这里的做法 |
|---|---|
| 抄题、画格子、分类，费时又容易半途而废 | 拍照发图即可，AI 转写并归档；你不用敲命令、不用分类 |
| 整理完就再也没看过 | `next_review` + 间隔重复（+3 / +7 / +30 天），到点提醒你重做哪几道 |
| 同一道题反复错、同一个知识点反复抄 | 强制查重：同一道题只加一行「重做记录」，错 3 次自动打 `高频错题` 标签 |
| 对着答案"重做"，其实在骗自己 | 每周生成**不含答案**的可打印「重做单」，在纸上真算一遍 |

## 三步上手

### 1. 装 Obsidian，把本库作为库打开

到 [obsidian.md](https://obsidian.md) 下载安装（免费）。打开时选择「**以文件夹作为库打开**」，指向本库目录。

> 视图用的是 Obsidian **内置的 Bases**（`错题-总览.base` / `错题-按科目.base`），**不需要装任何插件**。建议 Obsidian 版本 ≥ 1.9。

### 2. 告诉 AI 用这个目录

用你惯用的 AI 工具，**把本库文件夹设为工作目录**。然后说一句：

```
启动项目
```

AI 会确认目录并读取 `AGENTS.md` 里的完整规则。之后直接发错题图片就行。

> `AGENTS.md` 是这套系统的唯一入口和规则来源。换 AI 工具不用改任何东西——它们大多会自动读取工作目录下的 `AGENTS.md`；若某个工具不自动读，跟它说一句"先读 `AGENTS.md` 再按里面的规则做"即可。

### 3. 开始发图

- 发**错题照片** → 自动归档
- 发**生词** → 记进单词本，补齐考研常考义项和搭配
- 说 **"今天该重做什么"** → 出复习清单
- 说 **"出重做单"** → 生成可打印的无答案重做单
- 说 **"处理收件箱"** → 归档 `收件箱/` 里拖进去的图片

## 目录结构

```
.
├── AGENTS.md              ← 核心：给 AI 的完整工作规则（唯一入口）
├── 使用说明.md            ← 给人看的：日常怎么用
├── 分类规则.md            ← 字段取值表（科目/模块/题型/错因/材料简称…）
├── 归档细则.md            ← 英语错题、生词、收件箱的细化规则
├── 复习计划.md            ← 长线阶段划分与间隔重复节奏
├── 启动项目.md            ← 可选：两条定时任务的完整规格
├── 首页.md                ← Obsidian 首页总览
├── 错题-总览.base         ← Bases 视图（待复习/高频/按材料…）
├── 错题-按科目.base       ← Bases 视图（数学/英语/政治/专业课）
├── 错题/<科目>/           ← 错题笔记（每道题一个 md）
├── 知识点/                ← 公式手册、方法速查、单词本、作文语料…
├── 模板/                  ← 错题笔记模板
├── 收件箱/                ← 黑洞区：图片拖进来等 AI 归档
│   ├── 已处理/            ← 归档后原图移到这里
│   └── 待确认/            ← AI 看不懂的，不猜，放这里等你说明
├── 重做单/                ← 生成的可打印重做清单
├── 附件/                  ← 错题原图
└── .zcode/commands/       ← 可选：ZCode 专属快捷命令 /cuoti /fuxi
```

## 关于 AI 工具

`AGENTS.md` 是一份**工具无关**的规则文件，用相对路径描述一切库内位置，因此可以原样复制到任何机器、任何目录。

| 工具 | 自动读取 `AGENTS.md` |
|---|---|
| ZCode | 是 |
| Qoder | 是 |
| WorkBuddy | 是 |
| Cursor / Claude Code 等 | 大多支持 |

`.zcode/commands/` 下的 `/cuoti`、`/fuxi` 只对 **ZCode** 有效，用别的工具可直接忽略——它们只是少打几个字的捷径。

## 可选：让它自动跑

本库支持两条**可选**的定时任务（不配也完全能用，手动说一句即可）：

- **每周日 10:00** —— 生成当周重做单
- **每天 23:00** —— 扫描 `收件箱/` 并归档

完整任务规格见 `启动项目.md`。把里面的 `【库根目录】` 替换成你的真实路径，然后在你所用 AI 工具的「自动化 / 定时任务」入口里建一遍即可。

## 隐私说明

本库是**空框架**：所有笔记都是模板、说明文字和空表格，**不含任何已有错题或个人信息**。工具目录下的 `AGENTS.md` 规则中也用相对路径，不绑定任何本机路径。你可以安全地复制、修改、再分发。
