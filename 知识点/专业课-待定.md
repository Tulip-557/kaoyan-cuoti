## 电子类考研常见专业课（选院校时参考）

| 科目 | 常见考查重点 | 复习特点 |
|---|---|---|
| **信号与系统 / DSP**（已开始） | 傅里叶变换、拉普拉斯变换、Z 变换、卷积、采样定理、系统稳定性、滤波器设计 | 数学性强，公式链长，适合建公式手册 |
| **模拟电子技术** | 三极管放大电路、差分放大器、电流源、负反馈、频率响应、运放应用、功放、稳压电源 | 电路分析靠套路，做题量大；结论需要背 |
| **数字电子技术** | 组合逻辑、时序逻辑、触发器、计数器、状态机、ADC/DAC、存储器 | 题型固定，画图与设计题多，容易通过刷题提分 |
| **通信原理** | 调制解调、信噪比、香农公式、信道编码、误码率分析 | 概念 + 计算并重，公式多需推导 |
| **电磁场与电磁波 / 微波** | 麦克斯韦方程、传输线、波导、天线基础 | 物理图像 + 矢量运算，难度较高 |
| **电路** | 节点网孔分析、戴维南等效、动态电路、正弦稳态 | 基础课，计算量大但规律性强 |
| **半导体物理 / 器件** | 能带、PN 结、MOSFET 特性 | 概念密集，偏记忆 + 理解 |
