# 信号与系统 · 方法速查表

> **这张表回答"我该想到什么"**，不是"这个知识点是什么"（后者看 [[信号与系统-公式手册]]）。
> 只有两列：**看到什么（题干特征）→ 先想什么（方法 / 定理）**。条目从你的错题里长出来——错一次、沉淀一条。

| 看到什么（题干特征） | 先想什么（方法 / 定理） |
|---|---|
| 含 √ 相减的极限 | 有理化 / 等价无穷小 |
| 周期信号的频谱 | 傅里叶级数系数 |
| 求系统对某输入的响应 | 先求 h(t) 再卷积；或变换域相乘再反变换 |
| 给零极点图问稳定性 | 连续看极点实部、离散看极点模长与单位圆 |
| 求逆变换遇到分式 | 部分分式展开 + 查常用变换对；或留数法 |
| 差分方程求全解 | z 变换 + 部分分式（或经典时域解法） |
| 抽样后频谱 | 原频谱周期延拓 + 混叠判断 |

**维护规则**

- 归档信号与系统错题时，如果这道题"应该想到某个方法"而你当时没想到（错因是「思路不会」「知识盲区」），我会加一条或在已有条目上补充。
- 同一条特征只写一条，写法统一；**不抄具体题目、不写答案**。
- 你也能随时直接说"这个我总想不到 XX"，我立刻加。
